# Documentation guide

Start with the guide for the task at hand. The English [README](../README.md)
and [Chinese README](../README.zh-CN.md) cover installation and first use.

| Task | Guide |
| --- | --- |
| Run commands, reuse presets, inspect a bundle | [CLI](CLI.md) |
| Use the desktop application | [GUI](GUI.md) |
| Read or save Excel results | [Excel](EXCEL.md) |
| Call the Python API | [API](API.md) |
| Interpret equations, units, assumptions and limits | [Scientific contracts](SCIENTIFIC_CONTRACTS.md) |
| Understand field aliases and engine differences | [Schema aliases](SCHEMA_ALIASES.md), [engine parity](ENGINE_PARITY.md) |
| Make a code or documentation change | [Contributing](../CONTRIBUTING.md), [agent workflow](AGENT_WORKFLOW.md), [project instructions](../AGENTS.md) |
| Understand module boundaries | [Architecture](ARCHITECTURE.md) |
| Validate numerical results | [Validation](VALIDATION.md), [analytic benchmarks](ANALYTIC_BENCHMARKS.md), [validation cases](../validation_cases/README.md) |
| Contribute an experimental or independent comparison | [Validation-case template](VALIDATION_CASE_TEMPLATE.md) |
| Prepare a software release | [Release procedure](RELEASE.md) |
| Prepare a JOSS submission | [Current submission guide](joss/README.md) |
| Check inherited source and licenses | [Source lineage](SOURCE_LINEAGE.md), [notice](../NOTICE.md) |

The dated reports in [evidence](evidence/README.md), the
[integration report](../INTEGRATION_REPORT.md), and the
[six-month plan](JOSS_6_MONTH_PLAN.md) describe their recorded snapshots. Use the
current guides, code and CI for present behavior; preserve historical evidence
instead of rewriting it as current results.
