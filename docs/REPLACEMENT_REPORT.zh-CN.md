# 两个原项目的功能继承与独立运行验证

日期：2026-09-27

改造前，DiffractScout 已覆盖候选相检索、CIF 分析和结果导出的主要流程，
但还不能完整替代 CIF2Peaks 和 PhaseScout。本轮将两个原项目的运行模块
纳入同一个安装包，补齐原有工作流入口，并完成 Windows 便携版构建。

## 现在如何使用

便携版解压后，双击 `start_gui.bat` 进入 DiffractScout。
主窗口的“兼容工作台”菜单提供两个入口：

- **CIF2Peaks**：原有 CIF 预览、批量峰表、连续谱线工作簿、晶体结构与重叠峰视图、
  Cij 输入、图片导出和中英文界面。
- **PhaseScout**：原有候选相查询、选取和下载界面。

PhaseScout 的完整批量检索、编号目录、适用合金标签、文献线索查询等命令行功能，
通过 `DiffractScout.exe compat phasescout --help` 查看。
旧版一键导出可使用 `quick_export.bat`，支持将 CIF 拖到启动器上。

从源码安装时，运行 `python -m pip install ".[complete]"`，
然后使用 `diffractscout gui` 或 `diffractscout compat --help`。

## 本轮补齐的能力

1. 原版 pymatgen 衍射计算及原有 CSV、JSON、Excel 导出格式。
2. 原版独立连续谱线工作簿，以及 SVG、PDF、EPS、PNG、TIFF 出图。
3. 原版候选相批量目录、命名和索引约定。
4. 弹性常数来源记录、离线文献检索链接和在线 OpenAlex 检索入口。
5. 两个原版桌面工作台与快速导出入口。
6. 真正执行构建、自检、完整目录打包的 Windows 便携版脚本。

两个原项目的源码目录均不再是运行依赖，且本轮没有修改它们。
原有 MIT 许可和来源文件哈希随项目保留。

## 已完成的验证

- 最终全量测试：**690 项通过，5 项跳过**；跳过项需要未公开分发的原项目 CIF 数据。
- 界面及兼容入口专项复验：**63 项通过**。
- 代码静态检查、文档检查和 Python 编译检查通过。
- 在源码目录外，从独立安装的 wheel 运行旧版峰表、谱线、离线文献线索导出，
  以及统一流程的计算与结果包校验，均通过。
- Windows 冻结程序完成离线演示及清单校验；实际处理 3 个 CIF，输出 83 条旧版峰记录。
- 冻结程序的 DiffractScout、CIF2Peaks、PhaseScout 三个窗口均成功启动并正常关闭。
- Windows ZIP 包包含 Tcl/Tk、拖放组件、示例、许可和完整运行目录。

## 对“完整替代”的准确说明

现在已经能够以一个独立项目提供两个原项目的运行功能；旧格式和旧计算行为
通过内置兼容工作台保留，统一流程继续提供严格的张量坐标系检查和可验证结果包。
这不是所有选项已合并到同一张界面的声明。

两个衍射引擎的结果不能默认逐值相同；兼容模式沿用原计算约定及输出语义，
不会自动获得统一流程的清单校验或更严格的张量坐标系判定。
文献线索也不会被当作数值 Cij。

本轮未进行带用户 API 密钥的 Materials Project 在线下载验收，
也未验证当前 OpenAlex 在线响应或人工拖放操作。离线测试和窗口启动
不能替代这些检查。本报告记录本地验证，不等同于远端 CI 通过或 GitHub Release 发布。

逐项能力对照、命令示例与来源说明见 [REPLACEMENT_AUDIT.md](REPLACEMENT_AUDIT.md)。
